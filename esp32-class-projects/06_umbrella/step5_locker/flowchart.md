# 스마트 보관함 — 실행 로직 순서도

## ① 전체 구조 — 부팅(setup)과 반복(loop)

```mermaid
flowchart TD
    A([전원 ON]) --> B["핀 초기화<br/>리드 4개 INPUT_PULLUP<br/>서보 4개 → 닫힘 20도"]
    B --> C{"WiFi 연결<br/>(최대 15초)"}
    C -- 성공 --> D["온라인 모드<br/>앱 명령 대기"]
    C -- 실패 --> E["오프라인 모드<br/>시리얼 전용"]
    D --> F["슬롯 상태 출력 + 시트 보고"]
    E --> F
    F --> G[/"loop 반복 시작"/]

    G --> H{"시리얼 입력 있나?"}
    H -- "r1~r4 / b1~b4 / s" --> I["명령 실행"]
    H -- 없음 --> J
    I --> J{"3초 지났나?<br/>(온라인일 때)"}
    J -- 예 --> K["Apps Script에서<br/>명령 읽기 ?action=cmd"]
    K --> L{"명령 있나?"}
    L -- "RENT:n / RETURN:n" --> I2["명령 실행"]
    L -- 없음 --> M
    J -- 아니오 --> M
    I2 --> M{"30초 지났나?<br/>(온라인일 때)"}
    M -- 예 --> N["슬롯 4칸 우산 유무를<br/>시트에 보고 ?action=report"]
    M -- 아니오 --> G
    N --> G
```

## ② 대여 (doRent) — `RENT:n` 또는 시리얼 `rn`

```mermaid
flowchart TD
    A([대여 명령: 슬롯 n]) --> B{"리드스위치 감지?<br/>(우산 있나?)"}
    B -- "없음" --> C["✗ 빌려줄 우산이 없음<br/>LED 경고 점멸"]
    C --> D["시트 대여 기록 취소<br/>?action=cancel"]
    D --> Z([끝])

    B -- "있음" --> E["서보 열림 (100도)<br/>『5초 안에 우산을 꺼내세요』"]
    E --> F["5초 대기"]
    F --> G["서보 닫힘 (20도)"]
    G --> H{"리드스위치 감지?"}
    H -- "없음 (우산 빠짐)" --> I["✓ 대여완료!<br/>LED 짧게 2회"]
    H -- "있음 (그대로)" --> J["✗ 대여실패<br/>LED 경고 점멸"]
    J --> K["시트 대여 기록 취소<br/>?action=cancel"]
    I --> L["슬롯 상태 시트 보고"]
    K --> L
    L --> Z2([끝])
```

## ③ 반납 (doReturn) — `RETURN:n` 또는 시리얼 `bn`

```mermaid
flowchart TD
    A([반납 명령: 슬롯 n]) --> B["시도 횟수 = 1"]
    B --> C["서보 열림 (100도)<br/>『5초 안에 우산을 꽂으세요』"]
    C --> D["5초 대기"]
    D --> E["서보 닫힘 (20도)"]
    E --> F{"리드스위치 감지?<br/>(우산 꽂혔나?)"}
    F -- "감지됨" --> G["✓ 반납완료!<br/>LED 짧게 2회"]
    G --> H["슬롯 상태 시트 보고"]
    H --> Z([끝])

    F -- "감지 안 됨" --> I{"3회째 시도였나?"}
    I -- "아니오" --> J["『다시 열게요』<br/>시도 횟수 +1"]
    J --> C
    I -- "예" --> K["✗ 반납실패<br/>LED 경고 점멸"]
    K --> H
```

## 한눈에 보는 핵심 규칙

| 상황 | 판정 기준 | 결과 |
|---|---|---|
| 대여 후 우산 없음 | 리드 감지 안 됨 | ✓ 대여완료 |
| 대여 후 우산 그대로 | 리드 감지됨 | ✗ 대여실패 → 시트 자동 취소 |
| 반납 후 우산 감지 | 리드 감지됨 | ✓ 반납완료 |
| 반납 후 우산 없음 | 리드 감지 안 됨 | 다시 열림 (최대 3회) → 그래도 없으면 ✗ 반납실패 |

- 열림 100도 / 닫힘 20도, 열려 있는 시간 5초 — 코드 상단 상수로 조정
- 명령은 앱(Apps Script 큐, 3초 폴링)과 시리얼(r/b/s) 두 경로 모두 같은 함수로 처리
